# Monday 2 November: plates for Codex to build (art-directed, the AI passports' standard)

Codex is the visual asset maker (Ruling, Krish, 2026-10-28). It builds each plate below as a real material object, the
way it built the two passports (`assets/plates/two-passports`: paper texture, guilloche, rosette, printed detail),
never a flat icon. Every plate carries only checked numbers; nothing on it is invented. Brand colours from
`config/ve/brand-tokens.json`: ink desk, cream paper, butter for follow.the.money and mint for the answer only.
Motion: Krish, 2026-10-31: "I want way more animation than ever before and movement." Every plate is built in layers so
it can move: parallax between layers, objects that ease in with a small overshoot and keep floating.
