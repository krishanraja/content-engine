Avatar 6

Generate Avatar 6 videos through the Model API on POST /v3/models/avatars or the Application API on POST /v3/videos.

Copy pageCopy page

Model API
The Avatar 6 model animates your reference media with the speech audio you supply. There is no avatar or voice to set up first.

curl -X POST "https://api.heygen.com/v3/models/avatars" \
 -H "x-api-key: $HEYGEN_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "model": "heygen-avatar-6",
 "reference_images": [{ "type": "asset_id", "asset_id": "IMAGE_ASSET_ID" }],
 "audio": { "type": "url", "url": "https://example.com/speech.wav" },
 "resolution": "2k",
 "motion_prompt": "Face the camera with a warm expression and use small, natural hand gestures."
 }'

Submission returns 202:

{ "data": { "video_id": "VIDEO_ID", "status": "pending" } }

Each media input accepts an HTTPS URL, an uploaded asset ID, or inline base64:

{ "type": "url", "url": "https://example.com/photo.jpg" }
{ "type": "asset_id", "asset_id": "ASSET_ID" }
{ "type": "base64", "media_type": "image/jpeg", "data": "<base64>" }

Reference media
Three ways to render a real person, based on your source material and your agreement with HeyGen:

ApproachAvailable toConsentAvatar slot

HeyGen avatar: a public avatar, or a digital twin made through HeyGen’s consent flow, on the Application API
All workspaces
Handled by HeyGen’s consent flow
Required for digital twins

Photo reference: a photo of the person, used with their permission. The model generates the motion.
All workspaces
No agreement needed
Not required

Video reference: the person’s own gestures and mannerisms, for the highest likeness. Add a matching photo for best results.
Enterprise customers
The person verifies consent with HeyGen before their video is submitted. Some contracts run without a consent step, reviewed case by case.
Not required
Videos of animated or illustrated characters work as references in every workspace.
A realistic reference video from a workspace without video-reference access returns 422 with realistic_human_reference_not_allowed. Use a photo reference or a HeyGen avatar instead, or contact sales for access.
Both Avatar 6 models require at least 2 seconds of reference video, whether you send a URL, base64 data, or an uploaded asset ID. A shorter reference returns HTTP 400 with code: invalid_parameter and param: reference_videos before a job is created.
Reference URLs and base64 inputs take videos up to 50 MB and images up to 32 MB. For a larger reference video, up to 200 MB, upload it with direct upload and pass its asset_id.

Application API
Render a HeyGen avatar look with Avatar 6 on POST /v3/videos by setting engine.type to heygen-avatar-6 or heygen-avatar-6-turbo. To animate a realistic person, use a digital twin created with HeyGen’s consent flow.

curl -X POST "https://api.heygen.com/v3/videos" \
 -H "x-api-key: $HEYGEN_API_KEY" \
 -H "Content-Type: application/json" \
 -d '{
 "type": "avatar",
 "avatar_id": "YOUR_LOOK_ID",
 "script": "Welcome. This clip was rendered with Avatar 6.",
 "voice_id": "YOUR_VOICE_ID",
 "engine": { "type": "heygen-avatar-6", "motion_expressiveness": "less" },
 "resolution": "2k",
 "aspect_ratio": "16:9",
 "motion_prompt": "Smile warmly and use small, open-handed gestures while speaking."
 }'

The response returns data.video_id.
This endpoint supports Avatar 6 for single-avatar requests (type: "avatar"). Avatar 6 is not supported for raw-image requests, studio scenes, batch creation, or scene editing. Omitting engine continues to select Avatar IV.
Use a compatible photo or video look. Check supported_api_engines on GET /v3/avatars/looks/{look_id}: eligible looks list heygen-avatar-6 and heygen-avatar-6-turbo. The look and reference must also satisfy the consent requirements.

curl "https://api.heygen.com/v3/videos/VIDEO_ID" \
 -H "x-api-key: $HEYGEN_API_KEY"
