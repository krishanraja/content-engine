Nectar Release Notes | iZotope
Nectar 5 Release Notes
Version 5.0.0 released November 23, 2026
Initial Major version release
System Requirements
Mac: macOS Sequoia (15.8), macOS Tahoe (26.7), macOS Golden Gate (27.2)
* Supported on Intel Macs and Apple silicon M-series Macs (in native & Rosetta).
Windows: Windows 10 (22H2), Windows 11 (24H2)
Plugin Formats
AU, AAX, VST3. All formats are 64-bit only.
DAWs/NLEs
Logic Pro 12 – 13, Pro Tools 2026, Ableton Live 12, Cubase 15 – 16, Nuendo 15, Fender Studio Pro 8, Reaper 7, FL Studio 2026, Adobe Audition 2026, Adobe Premiere Pro 2026, Davinci Resolve 21, Reason 14, Sequoia 2026, Samplitude 2026
Nectar Moments ARA: Logic (Rosetta), Pro Tools, Cubase, Nuendo, Fender Studio Pro, Reaper
Proceed to download
Version 4.2.0 released August 18, 2026
Advanced:
FIXED Obscured or overlapping text within inline edit fields on macOS Tahoe
FIXED GUI not displayed correctly after resizing, closing, and reopening the plugin window in Logic Pro running natively
FIXED Loading of certain Nectar 4 Delay factory presets
FIXED Crash that could occur upon closing the Key Detection pop-over panel when Nectar is in Trial mode
CHANGED Branding in product and installer
CHANGED Supported DAW/NLE versions
CHANGED Minimum supported macOS version to macOS Sonoma (14.7)
Standard:
FIXED Obscured or overlapping text within inline edit fields on macOS Tahoe
FIXED GUI not displayed correctly after resizing, closing, and reopening the plugin window in Logic Pro running natively
FIXED Crash that could occur upon closing the Key Detection pop-over panel when Nectar is in Trial mode
CHANGED Branding in product and installer
CHANGED Supported DAW/NLE versions
CHANGED Minimum supported macOS version to macOS Sonoma (14.7)
Version 4.1.0 released June 25, 2025
ADDED Windows HiDPI support
FIXED Failure to authorize Nectar Standard with iLok
CHANGED Supported DAW/NLE versions
CHANGED Minimum supported macOS version to macOS Ventura (13.7.4)
Version 4.0.1: released October 25, 2023
Fixed issue where certain buttons in the Voices module would steal hotkey focus from the DAW (e.g. transport control via spacebar).
Fixed issue with Backer presets loading custom references.
Fixed crash in Studio One when running Assistant on a mono AU instance.
Together with Boris FX, we’re obsessed with driving creative tech forward, committed to excellence in everything you see and hear.
