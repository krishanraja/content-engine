# Krish's approved standards that bind the Library

Read from Control Center get_approved_taste (repository krishanraja/makeyourmindup, lane production, floor) on 25 Nov 2026: 289 standards, 321 approved rows. These are the ones about how a template looks, moves or is laid out. Numbers are the floor's own order on that date. Check every template against every line before the host renders it. Where a line pins the retired look, the "Conflicts with v5" section says how the Library treats it; those lines change only when Krish rewords them.
