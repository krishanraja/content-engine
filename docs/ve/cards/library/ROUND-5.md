## Host acceptance

From this directory, `python render.py --alignment-only` runs the native-size ink test on every active item. The normal `python render.py` run includes the same gate, the sheets and the stress cases. `--check-only` uses the existing WebKit path. Results go to `.scratch/library/out/ink-alignment.json`, with the item, named column, element, target, measured pixel, deviation and pass/fail. A difference greater than 2 px, a missing required element, an undeclared element or a close/outro pixel mismatch makes the command exit unsuccessfully. The optional camera label appears only when its private image is absent. Photo-only exports have no letter edge to measure.

Each rendered line uses its signed canvas ink bearing at the fitted size, weight, style and tracking. The Fraunces face pins its variation axes for both measurement and paint. S3h, V4 and V9 use the drawn outlines of their expanded vector paths. The source artwork remains intact. Paired cells and side-by-side layouts have a named column for each side; a mark aligned on the right uses its painted right boundary.

The pixel gate compares the normal render with a second crop in which one element is hidden. It measures the difference against the independent column declarations saved in the registry. This isolates the letters or mark over grain and photography. The vertical close is also compared with the final vertical outro as a complete decoded image.
