# Mindmake Studio

This repository contains Krish's Mindmake Video and Carousel Studio. GitHub `main` owns code, schemas, configuration, and instructions. Control Center owns the safe cloud control and learning projection. The Windows runner owns exact media artifacts and execution history.

Before operating the Studio, read `AGENTS.md` and `docs/ENGINE_SESSION.md`. Then call `studio.session.open` through the configured `mindmake-studio` MCP server and inspect the returned capability set.

Do not mutate the engine or claim that feedback was captured when the gateway reports `read_only_untracked` or is unavailable. Never store a whole chat transcript. Use explicit feedback tools for exact feedback excerpts and structured artifact differences.

The phrase `Video engine` is a narrow launcher outside this repository. Do not interpret incidental references to video editing as permission to start a production workflow.
