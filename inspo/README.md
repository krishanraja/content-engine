# Video inspiration

Video references are media assets, so they live outside GitHub, in Drive's
`Ventures > Inspiration > Production Inspo` folder (ID in `config/style-references.json`,
`folder.drive_id`). The repository keeps this pointer so the references stay
discoverable without committing media.

## The first reference

The full list, with each one's study, is `references` in
`config/style-references.json` (nine on 4 November 2026). This is the first:

Inspiration never goes in the Video Engine folder: its `Inbox` is for
recordings awaiting intake and its `Archive` for finished videos. Inspiration
is never published or cut into a video. Since 14 October 2026 it is studied:
each home computer's recordings upload sends every video in Production Inspo
to the engine's library (`scripts/quick-edit/references.py publish`), and
`references.py study` measures it.
What each one teaches lives in `config/style-references.json`. The method is
in `docs/STYLE_REFERENCES.md`.
