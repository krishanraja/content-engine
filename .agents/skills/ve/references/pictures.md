# Carousels, memes, Notes images and off-day voiceover shorts

Rulings (Krish, 2026-11-13): "all the carousels should now be done in Claude, but using the Codex plug in as per the other usual workflows"; "memes and Notes images should go the same way"; "Off-day voiceover shorts should go the same way too".

- A carousel, a meme or a Notes image is made in a Claude session by content-engine from the locked v5 Library (Ruling, Krish, 2026-11-26): `python scripts/library/make_piece.py <piece> --set <set>` for a carousel, `python scripts/covers/make_covers.py <piece> --out <folder>` for its cover and thumbnails, with a `deck` that passes `scripts/carousel_check.py`. `config/asset-routes.json` names the command for every kind and the kinds the Library has no command for yet (a single meme image, a Notes image), which are not made another way. Codex, through the Codex plugin, builds only a photoreal still of the specific thing when no licensed photograph exists. Growth's renderer and its `codex/queue` are retired. The route is `docs/CAROUSEL-STANDARD.md`, "How a carousel is made".
- An off-day voiceover short or a meme video is a piece on this ve route like any other, run from a Claude session: the session writes the script and the signed spec, Codex builds the devices and plates from cards, `ve` renders, a separate reviewer watches and listens. The voice comes from wherever it comes from today. `scripts/produce_day.py` refuses an off-day piece.
